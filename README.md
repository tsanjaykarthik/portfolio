# Sanjay Karthik — Portfolio

Plain HTML/CSS/JS. No build step, no installs.

## Edit content
- **Text:** `data.js` (projects, jobs, skills, awards). Change words between the quotes.
- **Images:** drop files into `images/` — names are listed in `images/README.txt`.
- **Résumé:** replace `sanjay-karthik-resume.pdf` (keep the same file name).

## Put it online (GitHub + Vercel)
1. Create a GitHub account, then a new repository called `portfolio`.
2. On the repo page click **Add file → Upload files**, drag in *everything inside this folder* (not the folder itself), and click **Commit changes**.
3. Go to vercel.com, sign in with GitHub, click **Add New → Project**, pick `portfolio`, and click **Deploy** (leave every setting as default).
4. You get a live link like `portfolio-xyz.vercel.app`. Rename it under Project → Settings → Domains.

To update later: upload the changed files to GitHub again — Vercel redeploys on its own within a minute.

## Preview on your computer
Double-click `index.html`. (Images and everything work offline except fonts.)
